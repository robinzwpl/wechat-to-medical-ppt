# 培训课件大纲（模板 / 脱敏示例）

> 这是「公众号 → 医学培训 PPT」工作流的**大纲骨架示例**。
> 生成前必先出这样一份大纲给你确认，确认后才生成 `.pptx`。
> 文中 `⟨…⟩` 为占位符，正式生成时由工作流按实际主题 / 资料填写。

**主题**：⟨待填：疾病 / 药物 / 流程主题⟩
**依据**：⟨待填：公众号文章标题 + 补充资料（论文 / 指南名，期刊，年份，卷期页）⟩
**讲师**：⟨待填：XX医院 XX科 主任医师⟩
**受众**：科室低年资进修医生 · 应届本科生 · 研究生
**目的**：科普（讲清机制与管理逻辑）＋ 宣贯（把要点落到科室流程）
**建议时长**：45~60 min ｜ **计划页数**：⟨约 30~40 页⟩

> 图例：**【宣贯】** = 科室必须照做的红线；**【避坑】** = 易错点；**【受众】** = 分层表达提示。
