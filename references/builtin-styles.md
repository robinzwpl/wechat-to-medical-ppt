# 内置方案库（Built-in Styles）

> 本文件是 `wechat-to-medical-ppt` 技能的**内置模板规范**。
> 生成 PPT 且本次未使用用户自有模板时，**必须**按这里选定的某一套方案执行；不要临场自创配色。
> 每套方案都给了「来源」，可直接去 `tencent-pptx` 技能里读对应的完整设计原则。

五套方案按代号 B1–B5 命名。默认 **B1**。

| 代号 | 名称 | 主色 | 底子来源 | 一句话定位 |
|---|---|---|---|---|
| B1 | 医疗学术蓝 | `#1E4FA8` | `tencent-pptx` 学术风 | 指南解读 / 共识宣贯 / 通用学术讲课（**默认**） |
| B2 | 临床青绿 | `#0F766E` | B1 骨架换主色 | 疾病科普 / 患者教育 / 护理感控 / 生活方式 |
| B3 | 深蓝权威 | `#061F32` | `tencent-pptx` 商务咨询 | 制度流程宣贯 / 质控通报 / 科室管理汇报 |
| B4 | 高级灰文献 | `#586874` | `slidep` 高级灰文献模板 | 研究生组会 / 文献汇报 / 循证证据 |
| B5 | 红金政务 | `#C42819` | `tencent-pptx` 红金政务风 | 党建 / 思想政治 / 行政表彰 |

**选择原则（不提问时按此自动判定）**：

- 主题是**指南/共识/规范解读**，受众含进修医生与研究生 → **B1**
- 主题是**疾病科普、危险因素、饮食运动、患者教育** → **B2**
- 主题是**制度、流程、SOP、质控、不良事件、科室管理** → **B3**
- 主题是**机制、循证、RCT 数据、文献评读**，受众以研究生为主 → **B4**
- 主题是**党建、政治学习、表彰、行政动员** → **B5**

## B1 · 医疗学术蓝（默认）

**来源**：`tencent-pptx/references/designs/design-principle.academic.md`（学术风）。生成前读该文件拿完整版式规则。

**风格 DNA**：蓝白浅灰基底，表达证据、方法、结论；宝蓝主导，红/黄只作警示；金色为 0；不做营销海报。

### 配色

| 角色 | hex | 用途 |
|---|---|---|
| 主蓝 | `#1E4FA8` | 顶条、编号、强调 |
| 藏蓝 | `#0E3F8C` | 深底、章节扉页、重点卡 |
| 中蓝 | `#3D7BD9` | 描边、链接、图表第二色 |
| 浅蓝 | `#E8EFF8` / `#F0F5FC` | 卡片底、表头浅底 |
| 警示红 | `#D9534F` | 风险、禁忌、异常值（单页 ≤3%） |
| 数据黄 | `#FFC107` | 图表第二序列、核心金句（单页 ≤3%） |
| 文本 | `#1A2230` / `#4A5568` / `#6B7789` | 主 / 副 / 辅助（辅助已由 `#8B97A8` 修正，见"对比度红线"） |
| 线框 | `#D6DCE5` / `#E5E7EB` | 描边、表格线 |
| 背景 | `#FFFFFF` / `#F7F9FC` | 内容页主底 |

配色比：蓝族 35–55%，白底 30–55%，浅蓝 0–35%，红+黄 ≤5%，金 = 0。
**禁**：紫粉玫红、橙绿大色块、彩虹渐变、纯黑大底。

### 字体与字号

字体家族：`"Source Han Sans SC", "Microsoft YaHei", "PingFang SC", sans-serif`（≤2 套；封面英文长标题可用思源宋 / Times）。

| 层级 | px | 字重 |
|---|---|---|
| 封面中文主标 | 60–96 | Bold |
| 章节大数字 | 120–320 | Bold |
| 每页主标 | 32–40 | Bold |
| 卡内标题 | 24–30 | Bold |
| 正文 | 22–28 | Regular |
| 表格 | 18–22 | Regular/Bold |
| KPI 巨数字 | 72–120 | Bold |
| 注解 / 页脚 | 14–16 | Regular |

### 版式骨架（1280×720，左右安全距 40）

| 区域 | 范围 | 规则 |
|---|---|---|
| A 页眉 | 内容页用 A3：深蓝顶条 + 低透明线稿 | 全篇锁定一种 |
| B 标题块 | y 48–156 | 主标 32–40px Bold 深蓝 |
| C 内容区 | y 148–660，宽 1200 | 累计高 ≥476px，必须铺满 |
| D 页脚 | y 660–700 | 左 logo/单位 14px 灰，右页码 14–16px 深蓝 |

封面 / 目录 / 章节扉页 / 致谢页可省 A、D；其余页必须遵守母版。

### 组件倾向

- 常规卡：浅蓝底 + 淡描边；深蓝实色卡只作语义凸显，限频。
- 风险/禁忌：`#D9534F` 描边或左竖条 + 红字。
- 宣贯要点：藏蓝实色卡 + 白字。
- 表格：表头浅蓝底、线框 `#D6DCE5`、无斑马纹。

| Cyan | `#08A6F6` | 关键点缀、重点标记（单页 ≤5%） |
| 浅蓝 | `#99BDED` | 图表第三档、辅助色阶 |
| 警示红 | `#5A0E13` | 风险、不合格、超标 |

### 字体与字号

字体家族：`Arial, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`。
字号：Action Title 32–40 Bold；正文 **硬下限 ≥22px**；相邻层级拉开 ≥6px；单页字号种类 ≤5（扉页除外）。

### 版式骨架（1280×720，左右 padding 49–60）

| 区域 | 范围 | 规则 |
|---|---|---|
| A 页眉 | y 0–44 | 仅右上 14–16px 灰章节进度；禁彩色竖条 |
| B 标题块 | 起始 y = 44 | 顶部紧贴上沿，**禁在标题上方留大段空白**；双行约 90px；底部 1px 黑线作 B/C 分割 |
| C 内容区 | 分割线下 12px 起 至 y 660 | 上沿跟随 B 区实际底线 |
| D 页脚 | y 660–700 | 左 Source + Footnote 14–16px 灰两行；右页码 `NN` 14px 灰 |

### 组件倾向

- 能讲成结构图的，优先结构图，不堆卡片。
- 流程 / 制度页：横向泳道 + 编号节点，节点用 Navy 实色。
- 通报页：三栏 `现状 / 问题 / 整改`，整改栏用 Cyan 强调。
- 每页必须有 Source / Footnote（来源写"XX 共识 2026""科室制度 XX 号"）。

## 对比度红线（已逐项实测，务必遵守）

以下是五套方案里**容易踩坑的底色**。出现在这些底色上的文字，必须按"允许的文字色"选，否则阶梯教室后排看不清。

| 方案 | 底色 | 白字对比度 | 深字对比度 | 结论：文字该用什么色 |
|---|---|---|---|---|
| B1 | 中蓝 `#3D7BD9` | 4.17 | 3.83 | 只做**描边/图形**，不做文字底（≥24px 白字勉强可用） |
| B1 | 浅蓝 `#E8EFF8`/`#F0F5FC` | 1.1 | ~14 | 用主文本 `#1A2230` |
| B2 | 亮青 `#14B8A6` | 2.49 ❌ | 6.72 ✅ | 只做描边/图形；**禁**作为文字底 |
| B3 | Cyan `#08A6F6` | 2.69 ❌ | 6.24 ✅ | 文字用 `#061F32`；禁白字 |
| B3 | 浅蓝 `#99BDED` | 1.93 ❌ | 8.69 ✅ | 文字用 `#061F32`；禁白字 |
| B4 | 浅灰青 `#AAC1D3` | 1.86 ❌ | 11.28 ✅ | 文字用 `#000000`；禁白字 |
| B4 | 中灰青 `#8192A2` | 3.20 🟡 | — | 仅 ≥24px 大字可用白字 |
| B5 | 主金 `#E19825` | 2.41 ❌ | 7.50 ✅ | 文字用 `#171616`；**禁**白字 |
| B5 | 浅金 `#FFC000`/`#FFE79B` | 1.64 ❌ | 11.00 ✅ | 文字用 `#171616`；**禁**白字 |
| B5 | 粉红橙 `#F26B40` | 3.02 🟡 | 5.98 ✅ | 优先 `#171616`；白字仅 ≥24px |
| B5 | 深朱红 `#C42819` | 5.73 ✅ | — | 白字可用 |
| B5 | 暗红 `#A81810` | 7.49 ✅ | — | 白字可用 |

**通用规则**：

1. 正文（<24px）与底色的对比度必须 **≥4.5:1**；≥24px 的大字可放宽到 **≥3.0:1**。
2. 金 / 亮色块（B5 主金、B5 浅金、B2 亮青、B3 Cyan/浅蓝、B4 浅灰青）**一律配深字**，不要配白字——这是最容易出错的一处。
3. 小字（脚注、页码、来源，14–16px）一律用上面"允许的文字色"，不要用设计稿里的浅灰原值。
4. 深底（B1 主蓝/藏蓝、B2 主青绿/深青、B3 Navy、B4 主色/深蓝、B5 深朱红/暗红）配白字都达标，放心使用。
5. 自查方式（改色后跑一遍）：
   ```bash
   python <技能目录>/scripts/check_contrast.py     # 内置方案全量比对
   ```

## 生成时的执行要求

1. 选定方案后，**先读它的「来源」文件**（B1/B3/B5 读 `tencent-pptx` 的设计原则；B2 读 B1 再套用上表替换；B4 读 `slidep` 主题指纹）。
2. 全套页面统一使用该方案的配色与字号阶梯，**不得混用两套方案的色值**。
3. 每页必须满足该方案的"信息下限"（内容区铺满、卡片填充率、要点 ≤5 条）。
4. 在生成前的汇报里写明：「本次使用模板：**内置 · B1 医疗学术蓝**」这样带代号的表述。
5. 生成后把本次方案（代号 + 名称）写回 `04_模板/_模板配置.md` 的「默认模板」。
