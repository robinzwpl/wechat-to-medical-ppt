# wechat-to-medical-ppt

把「一篇公众号文章（＋ 你手动补充的文献资料）」变成「一份高年资主任医师讲给低年资医生 / 学生听的培训课件」。

- **讲师视角**：三甲医院高年资主任医师口吻（有临床经验、给科室规范）。
- **受众分层**：进修医生看"怎么做"、本科生看"是什么 / 为什么"、研究生看"机制与证据"。
- **目的**：科普（讲通俗）＋ 宣贯（讲清政策 / 指南 / 流程红线）。
- **科学性**：以你补充的论文 / 指南为准；公众号负责可读性与传播性。

---

## 一、安装

这是一个 WorkBuddy 技能（Skill）。克隆后把整个目录放进用户技能目录即可：

```bash
git clone git@github.com:robinzwpl/wechat-to-medical-ppt.git \
  "$USERPROFILE/.workbuddy/skills/wechat-to-medical-ppt"
```

最终必须存在：`...\.workbuddy\skills\wechat-to-medical-ppt\SKILL.md`（**不要多套一层目录**）。

### 依赖技能（在新电脑需具备，非本仓库文件）

| 技能 | 类型 | 作用 |
|---|---|---|
| `tencent-pptx` | WorkBuddy 内置 | 生成 `.pptx` |
| `pdf` / `pdfkit-py` | 推荐市场 | 解析补充资料里的 PDF |
| `agent-browser` | 官方插件 | 公众号正文被反爬时兜底抓取 |

> 生成前若需重装 PDF 解析依赖，可执行 `pip install -r requirements.txt`（本仓库脚本本身是纯标准库，不依赖这些）。

## 二、怎么用（三步）

1. **（可选）放模板**：有科室 / 医院的 PPT 模板就丢进 `04_模板/`。不放也没关系——会沿用上次那套，首次是内置的「医疗学术蓝」。
2. **给链接**：把网页版公众号文章链接发我，或把正文 / 链接文件放进 `01_公众号素材/`。
3. **（可选）放资料**：觉得公众号内容不够丰富时，把 PDF 论文、Word、PPT、图片等放进 `02_补充资料/`，生成时会自动读取并一起整合。

之后说一句：*"用这篇公众号做培训 PPT：\<链接\>"*。每次开跑前会先做**模板确认**（只问一次），再先出**大纲**给你确认，确认后才生成 `.pptx`。

## 三、本地素材与本地模板（重要）

本技能支持把**本地文件**纳入制作流程，无需联网也能用你手里的材料：

### 1. 本地增加素材（`02_补充资料/`）

把你手头的资料直接放进工作空间的 `02_补充资料/` 文件夹即可，支持：

- **PDF**（论文、指南、共识、说明书等，文本层 + 整页渲染均可解析）
- **Word（.docx）**、**PPT（.pptx）**
- **图片**（解剖图、流程图、数据表、示意图，直接作为插图）
- 纯文本 / Markdown

生成时会把这些资料与公众号内容**一起整合**进课件，冲突时**以你补充的资料（论文 / 指南）为准**，并在 PPT 末尾标注文献来源。

### 2. 本地添加 PPT 模板（`04_模板/`）

把模板文件放进 `04_模板/`，支持 `.pptx` / `.potx`：

- **自带模板（内置方案库，无需文件）**：B1 医疗学术蓝 · B2 临床青绿 · B3 深蓝权威 · B4 高级灰文献 · B5 红金政务。
- **你的本地模板（优先于内置方案）**：放入后自动出现在候选里，工作流会先把它**抽取成"视觉设计契约"**（配色 / 字体 / 字号层级 / 画布比例 / logo 背景），再按这份契约生成，保证新稿与你的模板观感一致；模板非 16:9（如 4:3）也能用，会自动换算坐标。
- 想要**严格保留模板母版上的院徽 / 页脚**，生成后在 PowerPoint 里「设计 → 主题 → 浏览主题」套一次原模板即可。

## 四、目录约定（在工作空间中）

| 文件夹 | 放什么 | 谁维护 |
|---|---|---|
| `01_公众号素材/` | 公众号链接、抓取后的正文 | 你放链接，工作流抓正文 |
| `02_补充资料/` | **你手动放入**的 PDF / Word / PPT / 图片等 | 你 |
| `03_输出PPT/` | 生成的大纲（.md）与课件（.pptx） | 自动生成 |
| `04_模板/` | **你手动放入**的 PPT 模板；`_模板配置.md` 与 `_提取/` 自动生成 | 你 ＋ 自动 |
